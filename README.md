# 家庭教師マッチング・決済管理システム (Tutor Management System)

保護者と家庭教師を効率的に繋ぎ、安全な取引を実現するデスクトップアプリケーションです。

---

## 📌 プロジェクト概要 (System Overview)
保護者が投稿した授業募集に対して、家庭教師が検索・応募を行えるマッチングプラットフォームです。
管理者が講師プロフィールの事前審査や手数料の決済確認を一元管理することで、個人間取引におけるトラブルを未然に防ぎ、双方にとって安全で信頼性の高い取引環境を提供します。

---

## 🎯 開発の目的 (Background & Purpose)
* **保護者:** 講師を探す手間と負担を軽減し、希望条件に合った家庭教師をスムーズに見つけられるようにする。
* **家庭教師:** 自身の条件に合った指導案件に直接アプローチし、効率的に求職機会を獲得できるようにする。
* **プラットフォーム:** 管理者による事前審査と決済確認を導入し、安心・安全な取引環境を確保する。

---

## 🛠 使用技術 (Tech Stack)
* **言語:** C#
* **フレームワーク / UI:** Windows Forms (.NET)
* **データベース:** SQL Server
* **データアクセス:** ADO.NET

---

## 📋 担当工程・役割 (Responsibilities)
* **役割:** メイン開発者
* **担当工程:** 要件定義、DB設計、UI設計、実装、テスト

---

## 🔑 主要機能 (Key Features)

| ユーザー種別 | 主な機能 |
| :--- | :--- |
| **保護者** | 授業募集の投稿、応募講師のプロフィール閲覧 |
| **家庭教師** | 募集案件の複合条件検索、授業への申し込み（応募） |
| **管理者** | 講師プロフィールの事前承認（審査）、手数料の決済確認・一元管理 |

---

## 💡 こだわりポイント (Technical Highlights)

* **3層アーキテクチャの採用**
  UI・業務ロジック・データアクセス層を分離し、コードの保守性と拡張性を向上させました。
* **セキュリティ対策の徹底**
  ADO.NETのパラメータ化クエリ（`SqlParameter`）によるSQLインジェクション対策および、パスワードのハッシュ化による安全なユーザー情報の管理を実装しました。
* **データ整合性の保証**
  `SqlTransaction`を活用し、マッチング成立や手数料決済などの複数テーブルにまたがる処理において、データの一貫性を確保しました。
* **ユーザー体験（UI/UX）の最適化**
  `ErrorProvider`を活用したリアルタイムの入力バリデーションと、ユーザー権限（保護者・家庭教師・管理者）に応じた動的な画面制御により、誤操作を防止しました。
* **複合条件検索と自動集計機能**
  指導科目やエリア等の複合検索処理を最適化し、保護者からのレビューに基づく講師の平均評価（レーティング）の自動集計ロジックを構築しました。
